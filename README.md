# AiSD_Lekcja6

# Zadanie 6.1


# Implementacja dwustronnej kolejki (ADT DEQUE) w języku C++ zaimplementowanej na bazie tablicy cyklicznej.

# Zawartość

basedeque.hpp - interfejs bazowy dla kolejki dwustronnej.

mydeque.hpp - szablon klasy MyDeque realizujący tablicę cykliczną.

main.cpp - program testujący działanie struktury i jej interfejsu.

Makefile - skrypt do kompilacji i uruchamiania programu.

# Jak uruchomić?

Wymagany jest system z zainstalowanym kompilatorem g++ oraz programem make. W terminalu wpisz jedną z poniższych komend:

make run – kompiluje program i od razu go uruchamia.

make – tworzy plik wykonywalny main.out.

make clean – usuwa wygenerowane pliki binarne i obiektowe.
